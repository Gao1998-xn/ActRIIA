# ActRIIA Research Repository
## Project Overview
This repository collects literature summaries, signaling pathway mechanisms, experimental protocols, target drug information and research notes related to **Activin Receptor IIA (ActRIIA)**.
All contents are for academic research only, not for clinical diagnosis or commercial usage.

## Research Scope
- Molecular biology of ActRIIA / ActRIIB receptor family
- Ligand binding characteristics (Activin, GDFs, BMPs)
- Canonical & non-canonical downstream signaling pathways
- Disease relevance: pulmonary hypertension, anemia, muscle metabolism, fibrosis
- Targeted therapeutic antibodies & fusion proteins: Sotatercept, Luspatercept and related candidates
- In vitro cell experiment protocols, data analysis notes

## File Structure
├── Literature_Summary/ # Integrated literature review, mechanism collation
├── Experimental_Protocols/ # Assay SOP, ELISA, cell functional experiment protocols
├── Target_Drugs/ # Drug mechanism, clinical trial information
├── Figures_Schematics/ # Signal pathway diagrams, experimental charts
└── README_CN.md # Chinese version introduction
